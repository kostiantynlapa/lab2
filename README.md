# Л2 — Лапа Костянтин, ТВ-61мп, варіант 9

Сегментація абонентів обленерго та пошук закономірностей (PCA, k-середні, метод Варда, карта Кохонена, асоціативні правила, перевірка пасток).

## Файли

- `lab2.ipynb` — ноутбук із виконаними клітинками та виводами;
- `report.md` — відповіді на питання;
- `segments.csv` — результат: поділ k-середніх на 2000 абонентів.

## Запуск

Дані варіанта покладіть у `variants/9/` (у репозиторій не входять):

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\jupyter lab lab2.ipynb
```
